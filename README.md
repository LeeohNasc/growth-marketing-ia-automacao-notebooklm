# Growth Marketing + IA + Automação com NotebookLM

## Contexto

Este projeto foi desenvolvido como parte de um desafio da DIO com o objetivo de utilizar Inteligência Artificial como ferramenta de aprendizagem ativa.

O tema escolhido foi Growth Marketing, Inteligência Artificial e Automação, buscando entender como essas áreas podem trabalhar juntas para gerar crescimento, eficiência e melhores decisões em negócios digitais.

## Objetivos de estudo

- Entender os principais conceitos de Growth Marketing;
- Identificar aplicações práticas de Inteligência Artificial em marketing;
- Compreender como automações podem reduzir tarefas manuais;
- Explorar como dados, IA e automação podem apoiar a tomada de decisão;
- Criar um material de estudo reutilizável para futuras revisões.
